# 场景类型和同步模式详解

## 场景类型

| 类型值 | 名称 | 说明 | 适用场景 |
|-------|------|------|---------|
| 1 | 正常场景 | 标准的数据同步场景 | 最常见的数据同步需求 |
| 2 | 触发器场景 | 由触发器驱动的场景 | 事件驱动的数据同步 |
| 3 | 消息回调场景 | 接收消息回调的场景 | Webhook 回调处理 |
| 4 | 推送数据场景 | 专门用于推送数据的场景 | 单向数据推送 |

### 类型选择指南

**正常场景（type=1）**
- 最常用的场景类型
- 支持双流和直推两种同步模式
- 适用于大多数数据同步需求
- 支持字段映射、数据过滤、预处理等完整功能

**触发器场景（type=2）**
- 由外部事件触发执行
- 适用于实时数据同步场景
- 需要配置触发器条件

**消息回调场景（type=3）**
- 接收外部系统的 Webhook 回调
- 适用于异步通知处理
- 需要配置回调 URL 和参数解析

**推送数据场景（type=4）**
- 专门用于单向数据推送
- 适用于数据上报、日志收集等场景
- 通常配合定时任务使用

## 同步模式

| 值 | 名称 | 说明 | 数据流向 |
|----|------|------|---------|
| 1 | 双流模式 | 双向数据流同步 | 源 ↔ 目标 |
| 2 | 直推模式 | 单向直接推送 | 源 → 目标 |

### 同步模式选择指南

**双流模式（syncModel=1）**
- 数据可以在源和目标之间双向同步
- 适用于需要保持两端数据一致的场景
- 示例：商品库存同步、订单状态同步

**直推模式（syncModel=2）**
- 数据只能从源单向推送到目标
- 适用于数据上报、备份等场景
- 示例：日志收集、数据归档

## 环境配置

| 值 | 名称 | 说明 |
|----|------|------|
| test | 测试环境 | 用于开发和测试 |
| formal / prod | 正式环境 | 用于生产环境 |

## 场景状态

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | 草稿 | 场景已创建但未发布 |
| 1 | 已发布 | 场景已发布，可以执行 |
| -1 | 禁用 | 场景被禁用，暂停执行 |

## 场景开放状态

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | 关闭 | 场景未开放 |
| 1 | 开放 | 场景已开放，可以接收数据 |
