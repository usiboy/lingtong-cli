## 常见问题

### Q1: 测试失败怎么办？

查看具体的失败信息：

```
[FAIL] 连接器查询失败: Error: API error (401)...
```

根据错误提示修复代码，然后重新运行测试。

### Q2: 有警告需要处理吗？

警告通常是非阻塞性问题，可以后续优化：

```
[WARN] 场景列表查询: Error: API error (404)...
```

这可能是因为测试环境中没有场景数据。

### Q3: 如何只测试某个阶段？

注释掉不需要的阶段，或临时修改测试脚本：

```bash
# 只测试认证模块
# section "阶段 1: 环境检查"
# ...
section "阶段 4: 认证测试"
# ...
```

### Q4: 如何在 CI/CD 中使用？

在 CI/CD 流程中添加：

```yaml
test:
  script:
    - cd lingtong-cli
    - ./test-full-validation.sh
```
